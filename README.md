# Iron Supply · Triagem

Protótipo local da triagem visual e base inicial para a próxima integração com Supabase.

## Estrutura

- `dist/`: interface do protótipo e manifesto da amostra.
- `data/drive-manifest.schema.json`: contrato dos links individuais do Google Drive.
- `data/triage-record.schema.json`: contrato dos registros de triagem que serão persistidos no Supabase.
- `servidor.py`: servidor local usado apenas no protótipo.

As imagens permanecem no Google Drive. O repositório guarda código e metadados; não contém cópias das imagens.
